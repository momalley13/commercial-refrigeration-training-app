# Commercial Refrigeration Training App

Self-contained offline web app for commercial refrigeration apprenticeship training.

## Features
- Theory modules (vapor-compression cycle, superheat/subcooling, etc.)
- Work instructions and SOPs
- Interactive diagnostic calculator (superheat, subcooling, oil differential)
- Field checklists with progress tracking
- Mobile-friendly / installable as PWA

## Install on iPhone Home Screen
1. Open the GitHub Pages site (or the raw index.html) in Safari.
2. Tap the Share button.
3. Scroll and tap **Add to Home Screen**.
4. Name it and tap Add.

The app works fully offline once loaded.

## Files
- `index.html` — Main app
- `manifest.json` — PWA manifest

Created for on-the-job and home self-training.
